# Experimental Deviations Log

This document records deviations, design alterations, and methodology shifts made during the lifecycle of the project.

| Date | Change | Reason |
| 2026-10-10 | Synthetic benchmark validation executed (v0.1-synthetic) | Success criterion failed: GatedModel utility does not cross zero (S*=None in ~99% resamples, MI=None) against 'zeros' and 'mean' null variants because GatedModel dampens pure noise more than zero/mean vectors, keeping S=1 accuracy above null accuracy. | 2026-10-10 | v0.5 VLM pilot: answer format adapted from open-ended first-token to 4-option multiple choice | Smoke test on Qwen2-VL revealed first-token probability distributions are diffuse for open-ended generative answers. To obtain clean, well-formed next-token probability vectors, the pilot evaluation format was adapted to 4-option multiple choice (A-OKVQA benchmark), reading the renormalized next-token distribution over letter tokens ['A', 'B', 'C', 'D'] at the final prompt position. Full-vocab probability mass on these 4 tokens is tracked and logged. |
| 2026-10-11 | v0.7 VLM main benchmark: swapblend corruption added, S* edge and significant crossing rules formalized post hoc, disjoint N=500 sample drawn | Pilot Criterion 2 was judged a weak pass because Gaussian utility crossed zero only at the final grid point (S*=1.0), which yields no usable integration interval for MI, while patch mask utility did not cross zero (acc stayed above null). To induce genuine cross-modal utility inversion, a third corruption 'swapblend' ((1-S)*img + S*img_other via fixed seeded derangement) was added. Formalized analysis rules post hoc: (1) S* at the grid edge is reported as 'edge, no usable crossing'; (2) a significant crossing metric was defined as the first S where the upper bootstrap CI of U(S) < 0. Multi-model adapter architecture added supporting Qwen2-VL, SmolVLM, and InternVL2 with a --check mode (letter mass >= 0.90 threshold). Fresh sample of N=500 items drawn strictly disjoint from pilot items (results/derived/main_ids.json). |
| 2026-10-11 | v0.7.1 SmolVLM token variants: letter probabilities sum bare and space-prefixed tokens | Pre-flight validation (--check) on SmolVLM-Instruct revealed 90% clean accuracy with sensible answer distributions, but reported mean letter probability mass 0.0000. The SmolVLM adapter (only) was updated to compute each letter's probability as the sum of full-vocab softmax probabilities over both variants, tracking total mass across all 8 tokens and renormalizing across the 4 choices. Qwen2-VL adapter and existing results remain untouched; no SmolVLM benchmark results existed prior to this fix. |
| 2026-10-11 | Pre-registered hypothesis: swapblend reliance-utility expectation (prior to main benchmark analysis) | Pre-registered expectation: under swapblend (deceptive/swapped visual context), if multimodal utility U(S) drops clearly negative at high severity (S >= 0.75) while normalized reliance R_hat(S) remains above 0.50, the model exhibits empirical multimodal over-trust (reliance-utility misalignment). Conversely, if R_hat(S) falls monotonically toward zero as U(S) degrades, the model exhibits quality-aligned reliance discounting. |

| 2026-10-11 | v0.7.3 SmolVLM readout adapted via assistant prefix after mass check failure | Despite 90% clean accuracy (correct logit ranking), SmolVLM's mean probability mass on bare + space-prefixed letter tokens was 0.0017 under the default prompt template, failing the mass >= 0.90 gate.
